## Provenance

The storage engine is original work. Its `db` facade, several serializers and a
number of regression scenarios were ported from earlier MapDB releases
(MapDB 1, 2 and 3, https://github.com/jankotek/mapdb) by the same author. The
Go implementation in this repository is a port of the Java reference
implementation (mapdb-java-store), alongside the Rust and Zig ports.

This project does **not** derive from Eclipse Collections.
